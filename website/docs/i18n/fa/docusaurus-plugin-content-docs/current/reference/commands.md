# دستورها

‏Lore سه دستور اسلش دارد که درون Claude Code اجرا می‌شوند.

## `/lore:init`

اسکفولدِ یک پروژه‌ی مستنداتِ جدید (ویزاردِ تعاملی).

- سه چیزِ اساسی را می‌پرسد: **نام محصول**، **زبان مستندات**، و **این‌که آیا ویوئر Docusaurus نصب شود**.
- لایه‌ی مستندات (`docs/` و پیکربندیِ پروژه) و به‌اختیار یک سایت Docusaurus را تولید می‌کند.
- هرگز فایل‌های موجود را بازنویسی نمی‌کند — اجرا در یک مخزن موجود امن است.

← [شروع سریع](../getting-started/quick-start.md)

## `/lore:config`

تنظیماتِ یک پروژه را هر زمان پر یا ویرایش کنید. هر سؤال اختیاری است و دستور idempotent است.

- آدرس سایت، توضیح محصول، منابع مورد اعتماد، قالبِ نگارش، رنگ برند.
- اعمالِ دوباره‌ی نام محصول یا زبان مستندات.
- روشن یا خاموش‌کردنِ ویوئر Docusaurus.

← [پیکربندی یک پروژه](../getting-started/configure.md)

## `/lore:add-docusaurus`

افزودنِ ویوئر Docusaurus به یک پروژه‌ی فقط-مستنداتِ موجود.

- آخرین Docusaurus را می‌گیرد، پیکربندی و استایلِ Lore را overlay می‌کند، و سایدبار را به مستنداتِ شما سیم‌کشی می‌کند.
- وقتی زبان مستندات راست‌به‌چپ است، لایه‌ی RTL و فونت فارسی را اضافه می‌کند.

← [افزودن ویوئر Docusaurus](../guides/add-docusaurus.md)
