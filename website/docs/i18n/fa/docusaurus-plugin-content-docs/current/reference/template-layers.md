# لایه‌های قالب

وقتی Lore یک پروژه را اسکفولد می‌کند، لایه‌های مستقل و اختیاری را ترکیب می‌کند. آن‌ها به‌صورت غیرمخرب کپی می‌شوند — فایل‌های موجود هرگز بازنویسی نمی‌شوند.

| لایه | چه زمانی | چه فراهم می‌کند |
|------|----------|-----------------|
| **لایه‌ی مستندات** | همیشه | پوشه‌ی مستندات، پیکربندیِ پروژه (شامل تعریف انجام‌شدن)، یک لاگِ درس‌های آموخته‌شده، و یک قالبِ سند. |
| **پایه‌ی Docusaurus** | اگر ویوئر را انتخاب کنید | پیکربندی، سایدبار و استایلِ برندِ Docusaurus. خودِ فریم‌ورک تازه گرفته می‌شود، بسته‌بندی نمی‌شود. |
| **دارایی‌های RTL** | ویوئر + یک زبانِ راست‌به‌چپ | فونت فارسیِ self-hosted و استایل‌شیتِ راست‌به‌چپ. |

## لایه‌ی مستندات

پایه‌ی همیشه‌حاضر. این لایه تعیین می‌کند که *چگونه* مستندات در این مخزن نوشته و اعتبارسنجی می‌شود — [تعریف انجام‌شدن](../concepts/definition-of-done.md)، قواعد مسیر تصویر و frontmatter، و ساختار مرجعِ سند — مستقل از این‌که آیا اصلاً یک سایت قابل‌مرور اضافه کنید یا نه. قواعدِ همیشه‌روشن در فایلِ متعلق‌به‌پلاگینِ `lore-methodology.md` می‌مانند که `CLAUDE.md` نازکِ پروژه آن را import می‌کند؛ یک هوکِ `SessionStart` این فایل را هنگام `/plugin update` به‌روز نگه می‌دارد، و `CLAUDE.md` لایهٔ مختصِ محصولِ شما را نگه می‌دارد.

## پایه‌ی Docusaurus

یک overlay، نه خودِ فریم‌ورک. ‏Lore **پیکربندی و استایلِ** خود را به‌شکل یک لایه‌ی نازک نگه می‌دارد؛ فریم‌ورک Docusaurus در زمان اسکفولد تازه با `create-docusaurus@latest` گرفته می‌شود، پس همیشه روی نسخه‌ی جاری شروع می‌کنید. به همین دلیل است که ویوئر [اضافه می‌شود](../guides/add-docusaurus.md) نه این‌که vendor شود.

## دارایی‌های RTL

فقط زمانی اضافه می‌شود که هر دو شرط برقرار باشند — یک ویوئر *و* یک زبانِ مستنداتِ راست‌به‌چپ. این لایه [فونت Vazirmatn و چیدمان RTL](../concepts/multilingual-rtl.md) را روی استایلِ پایه فراهم می‌کند.
