## About these docs

Each section documents scenarios, business rules, and product behavior, based on the trusted sources defined in `.claude/CLAUDE.md` (§1 Trusted Sources).

## Producing content

Use the Lore plugin skills to generate documentation from Figma, a brief, or the live site:

- `lore:figma-to-doc` — from Figma design files
- `lore:brief-to-doc` — from a brief / PRD / user story
- `lore:site-to-doc` — from observing the live product
- `lore:documentation-reviewer` — validate against the Definition of Done
